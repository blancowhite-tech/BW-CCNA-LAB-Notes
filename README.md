Repositorio de documentación y laboratorios para la preparación del examen **Cisco CCNA 200-301 v1.1**, desarrollado bajo el proyecto **Blancowhite Tech**.

## 🎯 Objetivo

Aprobar el examen CCNA 200-301 v1.1 antes de su retirada (2 de febrero de 2027), combinando los contenidos teóricos de Cisco Networking Academy con laboratorios prácticos en Packet Tracer.

## 📂 Estructura

- `01_NetAcad_Notes/` - Apuntes y resúmenes de los módulos teóricos.
- `02_Packet_Tracer_Labs/` - Laboratorios documentados (y archivos `.pkt`).
- `03_Troubleshooting/` - Retos de resolución de fallos.
- `04_Simulacros/` - Resultados de los exámenes de práctica.

## 🧰 Entorno

- **SO:** Kali Linux (VM)
- **Simulador:** Cisco Packet Tracer 9.0.1
- **Documentación:** Markdown / GitHub

## ⚠️ Filosofía de trabajo

1. No copiar y pegar configuraciones sin entenderlas.
2. Documentar cada fallo y su solución.
3. Priorizar el dominio de *IP Connectivity* (25%) y *Network Access* (20%).
